About me

Hi, I'm Cody — a software engineer and full-stack web developer based in Colorado Springs. I specialize in building web applications using modern JavaScript frameworks, Python and Django, responsive CSS layout structures, and REST API backends, and I'm comfortable working across the whole stack, from the database up to the interface.

Background

In April 2019, I stepped away from a first career — as a professional and collegiate hockey player, and later in hockey operations and management — to become a full-time stay-at-home parent. While home with my kids, I completed a Full-Stack Web Development Certification through CareerFoundry, on top of a B.S. from Castleton University, and started building real projects: REST APIs, React and Angular front ends, and full Django applications like the Recipe Manager App on my work page. That project brought together everything I'd learned — backend, database, and even data reporting — and it's what convinced me to make software engineering my full-time career.
